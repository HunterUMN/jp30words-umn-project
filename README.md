# JP30Words Student Project
The JP30Words is a japanese language learning website with resources and a test that the user can take to test their skill and improve.

Core features:
- Front page with information and resources related to Japanese learning.
- A test page with a flash card test programmed in Javascript with four modes: Nouns, Verbs, Adjectives, and Everything.
- Navigation menus to make the website easier to use.

Some instructions for the test:
- Use Romanji to type in the answers.
- If you get more than 5 right you 'pass'.
- You may click 'skip' when you get stuck.

I believe it is a good proof of concept and I learned a lot making it!
